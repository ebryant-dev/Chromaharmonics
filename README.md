# ChromaHarmonics

A color harmony generator with an interactive color wheel, fine-grained angular control, and multiple presentation styles.

## Features

- **8 harmony modes** — Analogous, Monochromatic, Complementary, Split-Complementary, Triadic, Tetradic, Square, Shades & Tints, and Freeform
- **Interactive color wheel** — drag the base handle to rotate the palette; drag harmony handles to adjust the spread angle
- **Per-color editing** — nudge hue, saturation, and lightness on any primary color; add tints and shades to any group
- **Overlay swatch display** — label chip + action buttons in the color block, info bar below with Hex, RGB, and HSL values
- **Export** — Copy all hex values, download JSON, PNG, or SVG

## Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Running locally

```bash
cd chromaharmonics
npm install
npm run dev
```
